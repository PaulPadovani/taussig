La démarche

Préserver le sens.
Préparer le partage.

TAUSSIG propose une représentation structurée du cathétérisme cardiaque congénital, pensée pour relier les questions cliniques aux données de recherche.

Trois objets distincts

Le diagnostic décrit la cardiopathie congénitale. La condition décrit un état évolutif. L’implant représente un dispositif qui possède sa propre identité. Cette séparation évite de réunir des informations de nature différente dans un seul libellé.

L’acte comme contexte

Le cathétérisme relie les abords, l’anesthésie, les gestes et les mesures. Une mesure est décrite par sa propriété, son site, sa modalité et sa phase lorsqu’ils sont renseignés.

Deux représentations complémentaires

Le modèle relationnel décrit les objets et leurs relations. Le dictionnaire propose leur correspondance avec FHIR R4. Les profils FHIR documentent les règles de cette représentation.

Des correspondances à examiner

La matrice terminologique compte les correspondances renseignées dans le catalogue local. Elle ne démontre pas une couverture clinique validée : une cellule vide ne prouve pas qu’un code n’existe pas.

État scientifique

Ce que permet cette version.

Le modèle relationnel v4, le dictionnaire v6 et les correspondances proposées sont consultables. Ils constituent un travail de recherche en cours. La validation technique d’une représentation ne remplace pas une revue clinique ni une évaluation indépendante. Ce site ne fournit pas de recommandations de prise en charge.

Corpus et reproductibilité

Une démonstration structurée et partielle, entièrement fictive, accompagne l’explorateur de trajectoires. Aucun compte rendu du corpus n’est embarqué. Les corpus de comptes rendus fictifs feront l’objet d’une diffusion distincte sur Hugging Face, avec leur documentation propre. Les fichiers proposés concernent le modèle et son dictionnaire. La page Trajectoires permet aussi de charger un Bundle mono-patient localement ; elle ne transmet ni ne stocke le fichier sur un serveur.
