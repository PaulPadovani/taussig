Profil de ressource: TAUSSIG — Implant cardiaque (substrat longitudinal) ( Expérimental )

URL officielle: https://taussig/fhir/StructureDefinition/taussig-cardiac-implant Version: 0.8.1
Active à date du 2026-11-09 Nom computable: TaussigCardiacImplant

Dispositif implanté persistant (conduit, valve, stent, occluder…). État clinique courant en extension (Device.status ne couvre pas functional/degenerated/…) ; chaînage valve-in-valve ; site anatomique SNOMED ; UDI.

Utilisations:

  • Référence ce Profil: Implant précédent, TAUSSIG — Mesure clinique (delta pre/post), TAUSSIG — Pose et port d'un implant and TAUSSIG — Geste interventionnel
  • Exemples pour ce/t/te Profil: Device/ex-prior-implant and Device/ex-taussig-cardiac-implant

Vous pouvez également vérifier les usages dans le FHIR IG Statistics
