Les systèmes et classifications tiers conservent leurs conditions de réutilisation. Les cinq catégories fines de dispositifs de fermeture utilisent des codes locaux TAUSSIG. La validation technique ne remplace pas la validation clinique des correspondances.

TAUSSIG — CardiacCondition (lésions résiduelles/acquises/post-chir) Working set des conditions cardiaques évolutives de la POC (distinct du diagnostic congénital figé) : 61 lésions résiduelles/acquises codées en IPCCC, plus 13 états d'étape chirurgicale codés en ECHSA — l'IPCCC ne code pas l'état « status post » d'un montage (Fontan, Glenn, MBTS…), d'où un ValueSet multi-systèmes. ICD-10 = donnée dérivée (crossmap IPCCC). Le typage residual/acquired/post-chir est un choix clinicien à la saisie (CardiacCondition.condition_type), pas une propriété du code.
TAUSSIG — Codes d'anthropométrie per-cathétérisme Codes LOINC utilisés pour poids, taille et surface corporelle au moment du cathétérisme.
TAUSSIG — Codes d'exposition et contraste Codes des observations quantitatives liées à l'exposition radiologique et au contraste.
TAUSSIG — Complications / événements indésirables (SNOMED CT, interopérabilité) Working set SNOMED CT des complications péri-procédurales du cathétérisme congénital (couche d'interopérabilité FHIR AdverseEvent.event / Condition.code). Résolu sur le SMT depuis les complications IPCCC/EPCC retenues. À valider cliniquement.
TAUSSIG — Complications péri-procédurales (IPCCC) Axe IPCCC des événements indésirables du cathétérisme congénital retenus pour la POC. La granularité IPCCC est plus grossière que la curation française : plusieurs libellés cliniques peuvent partager un même code (regroupés ici sous le libellé IPCCC officiel).
TAUSSIG — Conditions de mesure  
TAUSSIG — Diagnostics congénitaux (CIM-11 MMS) Axe de classification diagnostique de la POC : énumération des entités CIM-11 MMS retenues pour les cardiopathies congénitales, avec le libellé français officiel de l'OMS. Liaison extensible : un code CIM-11 hors liste reste admis, mais l'autocomplétion et les statistiques se font sur ce working set curé.
TAUSSIG — Diagnostics congénitaux (IPCCC) Équivalents IPCCC des diagnostics congénitaux du working set CIM-11 (codage parallèle de précision clinique). Un même code IPCCC peut répondre à plusieurs entités CIM-11.
TAUSSIG — Dérivation  
TAUSSIG — Gestes de cathétérisme (IPCCC) Axe IPCCC des gestes de cathétérisme congénital retenus pour la POC (gestes diagnostiques, interventionnels et hybrides). Remplace, pour l'autocomplétion, la liaison à la short list IPCCC de 1 822 codes, inexploitable comme menu.
TAUSSIG — Grade de régurgitation (valeurs codées) Échelle qualitative de la régurgitation valvulaire, valeur de la propriété de mesure regurgitation_grade (Observation.valueCodeableConcept). Qualifier values SNOMED CT dont l'existence et le libellé FR ont été vérifiés sur le SMT ; le choix de l'échelle reste à valider cliniquement.
