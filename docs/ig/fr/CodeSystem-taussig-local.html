Concepts nécessaires au modèle et vérifiés absents des terminologies de référence. Chaque code documente l'absence constatée.

Ce système de codes est référencé dans la définition des ensembles de valeurs suivants :

  • TAUSSIG — Sites anatomiques de mesure/geste (validé)

This case-sensitive code system https://taussig/fhir/CodeSystem/taussig-local defines the following code:

CodeAffichageDéfinition
TAUSSIG-CAVOPULM-INF Dérivation cavopulmonaire inférieure (VCI vers artère pulmonaire)

Anastomose entre la veine cave inférieure et l'artère pulmonaire, isolée. SNOMED CT ne fournit de concept que pour la dérivation supérieure (443327008) et pour la dérivation totale (443298009), et aucune structure corporelle pour la composante inférieure seule.
