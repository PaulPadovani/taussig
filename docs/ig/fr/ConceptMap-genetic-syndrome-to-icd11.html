ConceptMap: TAUSSIG — Syndromes génétiques (Orphanet) vers ICD-11 (Expérimental)

URL officielle: https://taussig/fhir/ConceptMap/genetic-syndrome-to-icd11 Version: 0.8.1
Draft à date du 2026-11-09 Nom computable: GeneticSyndromeToIcd11

Correspondance des 17 syndromes génétiques TAUSSIG (OrphaCode) vers ICD-11. Équivalence vue depuis l'OrphaCode (source) : HARVEY ne déduit le code que si la correspondance est « equivalent » ou « wider » et unique (décision A3). « unmatched » : aucun code ne convient. Qualification : dictionnaire v6.1, onglet Correspondances Cliniques (décision A4). Relations CIM validées par Orphanet (Orphadata, produit 1 FR, 2025-12-09, CC BY 4.0) : E → equivalent, NTBT → wider, BTNT → narrower.

Langue : fr
