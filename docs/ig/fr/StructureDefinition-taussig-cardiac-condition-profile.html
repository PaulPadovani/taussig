Profil de ressource: TAUSSIG — Condition cardiaque évolutive ( Expérimental )

URL officielle: https://taussig/fhir/StructureDefinition/taussig-cardiac-condition-profile Version: 0.6.1
Active à date du 2026-10-31 Nom computable: TaussigCardiacCondition

Statut actuel de la cardiopathie : état d'étape chirurgicale (status post ECHSA) OU lésion résiduelle/acquise. Codage IPCCC primaire + CIM-10 + SNOMED + ECHSA. Type (residual/acquired/post_surgical) = choix clinicien d'instance.
