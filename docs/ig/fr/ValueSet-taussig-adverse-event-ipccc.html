ValueSet: TAUSSIG — Complications péri-procédurales (IPCCC) (Expérimental)

URL officielle: https://taussig/fhir/ValueSet/taussig-adverse-event-ipccc Version: 0.1.0
Draft à date du 2026-10-31 Nom computable: TaussigAdverseEventIpccc

Axe IPCCC des événements indésirables du cathétérisme congénital retenus pour la POC. La granularité IPCCC est plus grossière que la curation française : plusieurs libellés cliniques peuvent partager un même code (regroupés ici sous le libellé IPCCC officiel).
