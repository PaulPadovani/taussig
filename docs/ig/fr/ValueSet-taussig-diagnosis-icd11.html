ValueSet: TAUSSIG — Diagnostics congénitaux (CIM-11 MMS) (Expérimental)

URL officielle: https://taussig/fhir/ValueSet/taussig-diagnosis-icd11 Version: 0.1.0
Draft à date du 2026-10-31 Nom computable: TaussigDiagnosisIcd11

Axe de classification diagnostique de la POC : énumération des entités CIM-11 MMS retenues pour les cardiopathies congénitales, avec le libellé français officiel de l'OMS. Liaison extensible : un code CIM-11 hors liste reste admis, mais l'autocomplétion et les statistiques se font sur ce working set curé.
