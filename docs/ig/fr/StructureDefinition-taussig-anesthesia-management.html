Profil de ressource: TAUSSIG — Gestion anesthésique ( Expérimental )

URL officielle: https://taussig/fhir/StructureDefinition/taussig-anesthesia-management Version: 0.8.1
Active à date du 2026-11-09 Nom computable: TaussigAnesthesiaManagement

Prise en charge anesthésique du cathétérisme. Type d'anesthésie en code (générale, sédation, locale : SNOMED CT ; aucune anesthésie explicite : complément TAUSSIG) ; ventilation & ECMO en extensions ; antibioprophylaxie/anticoagulant portés par MedicationAdministration (ATC).

Utilisations:

  • Référence ce Profil: TAUSSIG — Administration médicamenteuse péri-procédurale
  • Exemples pour ce/t/te Profil: Procedure/ex-taussig-anesthesia-management
