CodeSystem: TAUSSIG — Conditions cardiaques évolutives (Expérimental)

URL officielle: https://taussig/fhir/CodeSystem/taussig-condition Version: 0.8.1
Draft à date du 2026-11-09 Nom computable: TaussigCondition

Terminologie d'interface TAUSSIG : 107 concepts (conditions cardiaques évolutives) à identifiant neutre jamais réutilisé (dictionnaire v6.1, décision A1). L'annotateur choisit le libellé ; les codes IPCCC, CIM-10, ECHSA sont déduits par les ConceptMaps taussig-condition-to-*, seulement quand la correspondance est « equivalent » ou « wider » et unique (décision A3).

Ce système de codes est référencé dans la définition des ensembles de valeurs suivants :

  • TAUSSIG — Liste des conditions cardiaques évolutives

Langue : fr

Propriétés

ipccc-origin ipccc-origin Coding Code IPCCC dont le concept est issu.
