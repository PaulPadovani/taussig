CodeSystem: TAUSSIG — Propriétés de mesure hémodynamique (Expérimental)

URL officielle: https://taussig/fhir/CodeSystem/measurement-property Version: 0.1.0
Draft à date du 2026-11-09 Nom computable: TaussigMeasurementProperty

Le QUOI d'une mesure de cathétérisme (modèle décomposé : propriété × site SNOMED). Codes TAUSSIG-local car aucune terminologie standard n'a de propriété intravasculaire générique sans site ; codage SNOMED secondaire générique fourni quand il existe.

Ce système de codes est référencé dans la définition des ensembles de valeurs suivants :

  • TAUSSIG — Propriétés de mesure (binding ClinicalMeasurement.concept)

Propriétés

Cette terminologie de référence (CodeSystem) définit les propriétés suivantes pour ses concepts
