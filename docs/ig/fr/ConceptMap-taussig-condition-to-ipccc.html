ConceptMap: TAUSSIG — Conditions cardiaques évolutives vers IPCCC (Expérimental)

URL officielle: https://taussig/fhir/ConceptMap/taussig-condition-to-ipccc Version: 0.8.1
Draft à date du 2026-11-09 Nom computable: TaussigConditionToIpccc

Correspondance des concepts TAUSSIG (conditions cardiaques évolutives) vers IPCCC. Équivalence vue depuis le concept TAUSSIG (source) : HARVEY ne déduit le code que si la correspondance est « equivalent » ou « wider » et unique (décision A3). « unmatched » : aucun code ne convient. Qualification : dictionnaire v6.1, onglet Correspondances Cliniques (décision A4).

Langue : fr
