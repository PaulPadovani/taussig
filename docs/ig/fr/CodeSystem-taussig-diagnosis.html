CodeSystem: TAUSSIG — Diagnostics cardiaques congénitaux (Expérimental)

URL officielle: https://taussig/fhir/CodeSystem/taussig-diagnosis Version: 0.8.1
Draft à date du 2026-11-09 Nom computable: TaussigDiagnosis

Terminologie d'interface TAUSSIG : 109 concepts (diagnostics cardiaques congénitaux) à identifiant neutre jamais réutilisé (dictionnaire v6.1, décision A1). L'annotateur choisit le libellé ; les codes ICD-11, IPCCC, CIM-10, ECHSA sont déduits par les ConceptMaps taussig-diagnosis-to-*, seulement quand la correspondance est « equivalent » ou « wider » et unique (décision A3).

Ce système de codes est référencé dans la définition des ensembles de valeurs suivants :

  • TAUSSIG — Liste des diagnostics cardiaques congénitaux

Langue : fr

Propriétés

Cette terminologie de référence (CodeSystem) définit les propriétés suivantes pour ses concepts

NomCodeTypeDescription
ipccc-origin ipccc-origin Coding Code IPCCC dont le concept est issu.
